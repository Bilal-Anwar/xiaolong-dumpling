# Xiaolong Dumpling

A responsive restaurant landing page built with HTML, CSS and JavaScript.

Includes category filters, dish detail dialogs, scroll reveals, mobile navigation and reduced motion support.

Open `index.html` in a browser. Deploy the repository on Vercel with Framework Preset **Other**, no build command, and output directory `.`.

The menu and stock food photography are illustrative. Confirm actual dishes, allergens, prices and restaurant details before using this as an official menu. Logo supplied by the brand owner; stock photography is loaded from Unsplash and fonts from Google Fonts.
